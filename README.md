# YouTube to MP3

A small, responsive interface for a private YouTube-to-MP3 converter.

The website is hosted with GitHub Pages. Conversion runs on the owner's PC through an authenticated HTTPS connection. It requires a private access code, and the PC must remain on and online.

The site contains no YouTube cookies or access codes. Browser-session access happens only on the connected PC. MP3 downloads use short-lived, single-use links.

GitHub Pages serves this interface only; it does not run the conversion tools.
